# EarTrainer — тренажёр музыкального слуха

Геймифицированный тренажёр для развития музыкального слуха. PyGame + numpy, без аудиофайлов.

## Статус: v0.1.0 (MVP)

- ✅ Процедурный синтез звука (ноты, интервалы, аккорды)
- ✅ Тренажёр интервалов (12 интервалов, 4 уровня сложности)
- ✅ 4 кнопки-варианта, клавиши 1–4, ПРОБЕЛ — прослушать
- ✅ Частицы при успехе, красная вспышка при ошибке
- ✅ Стрик, точность, счётчик ✓/✗
- ⏳ Тренажёр аккордов — в разработке
- ⏳ Тренажёр нот (perfect pitch) — в разработке
- ⏳ Статистика и сохранение прогресса — в разработке

## Установка
    source ../PyTetris/.venv/bin/activate
    python main.py

## Управление
- Клик по карточке — открыть режим
- ПРОБЕЛ — прослушать заново
- 1–4 — выбрать вариант
- ESC — назад в меню

## Архитектура
    synth.py          — синтез (sine/tri/square/saw + envelope)
    theory.py         — данные: интервалы, аккорды, ноты
    trainer.py        — движок: генерация вопросов, сессии, стрики
    effects.py        — частицы + вспышки
    screen_interval.py — игровой экран тренажёра
    theme.py, ui.py   — Material Design
    main.py           — роутинг состояний
