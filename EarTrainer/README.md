# EarTrainer — тренажёр музыкального слуха

Геймифицированный тренажёр для развития музыкального слуха: интервалы, аккорды, ноты.
Написан на PyGame, использует процедурный синтез звука (без аудиофайлов).

## Режимы
- 🎼 **Интервалы** — узнавание интервалов на слух
- 🎹 **Аккорды** — определение типа аккорда
- 🎵 **Ноты** — абсолютный слух (perfect pitch)

## Установка
    source ../PyTetris/.venv/bin/activate
    python main.py

## Управление
- ПРОБЕЛ — проиграть звук заново
- 1-9 — выбрать ответ
- ESC — назад в меню
