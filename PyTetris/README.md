# PyTetris — Neon Edition

Тетрис на PyGame: живая сетка, RPG-прогрессия, русский язык.

## ✨ Особенности
- 🌊 Живая сетка (волны + пульс)
- 💥 Волны очистки линий
- 🎮 Классика, спринт, мусор, дзен
- 🏆 17 достижений × 5 медалей
- 🃏 20 карт × 4 редкости
- 📅 Дейлики + недельные квесты + стрик
- 🛒 Магазин, календарь наград, профиль (10 званий)
- ⚡ DAS, T-spin, Perfect Clear, slow-mo
- 🎯 Ghost, danger zone, мини-карта
- 🎵 Чиптюн + fade in/out

## 🚀 Установка
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python main.py

## 🎮 Управление
    ← →     движение (DAS)
    ↓       soft drop
    ↑ / Z   поворот
    SPACE   hard drop
    C       hold
    P/ESC   пауза
    M       mute
    F1      справка
    F3      FPS
    F4      окно 75%/100%
    F11     fullscreen
    F5/F9   сохранение / загрузка
